
# 채용공고 기반 직무별 요구 기술 분석

원티드(Wanted) 채용공고 데이터를 수집하고 분석하여 IT 직무별 핵심 기술, 차별화 기술, 기술 조합 및 채용시장 요구 패턴을 파악한 데이터 분석 프로젝트입니다.

## 1. 프로젝트 개요

IT 직무를 준비할 때 어떤 기술을 우선적으로 학습해야 하는지 객관적인 근거를 마련하기 위해 진행했습니다.

채용공고에 등장하는 기술을 추출하고, 직무별 기술 등장률과 TF-IDF, 공동출현 관계 등을 분석했습니다.

| 항목 | 내용 |
|---|---|
| 데이터 출처 | 원티드(Wanted) |
| 수집 공고 | 1,273건 |
| 최종 분석 공고 | 724건 |
| 분석 직무 | 데이터 분석가, 데이터 엔지니어, 데이터 사이언티스트, 백엔드, 프론트엔드 |
| 기술 사전 | 표준 기술명 90개, 별칭 210개 |
| 분석 언어 | Python |
| 데이터 저장 | CSV, SQLite |

## 2. 프로젝트 진행 과정

1. 원티드 채용공고 API를 활용한 데이터 수집
2. SQLite 데이터베이스 적재 및 중복 검증
3. 공고 제목을 기준으로 5개 직무 재분류
4. 스킬 사전 기반 기술명 추출
5. 직무별 기술 등장률 분석
6. TF-IDF를 활용한 직무별 특징 기술 분석
7. 공동출현 횟수 및 Jaccard 유사도 분석
8. LLM 요구 현황, 경력별 기술 수, 직무 간 코사인 유사도 분석
9. 결과 시각화 및 인사이트 도출

## 3. 주요 분석 결과

### 3.1 직무별 핵심 요구 기술

| 직무 | 1위 | 2위 | 3위 |
|---|---|---|---|
| 데이터 분석가 | SQL (83%) | Python (61%) | Tableau (42%) |
| 데이터 엔지니어 | Python (69%) | SQL (63%) | AWS (57%) |
| 데이터 사이언티스트 | Python (74%) | LLM (56%) | Machine Learning (38%) |
| 백엔드 | AWS (58%) | Kubernetes (48%) | CI/CD (45%) |
| 프론트엔드 | React (95%) | TypeScript (83%) | Vue.js (59%) |

### 3.2 직무별 TF-IDF 상위 기술

| 직무 | 1위 | 2위 | 3위 |
|---|---|---|---|
| 데이터 분석가 | SQL | Tableau | Python |
| 데이터 엔지니어 | Python | Kafka | SQL |
| 데이터 사이언티스트 | Python | Deep Learning | PyTorch |
| 백엔드 | AWS | Kubernetes | CI/CD |
| 프론트엔드 | React | TypeScript | Next.js |

TF-IDF는 단순 등장률뿐 아니라 다른 직무에서의 기술 분포를 반영하여 상대적으로 두드러지는 기술을 확인하는 데 활용했습니다.

### 3.3 주요 기술 조합

| 기술 조합 | 공동출현 횟수 | Jaccard 유사도 |
|---|---:|---:|
| TypeScript + React | 184건 | 0.692 |
| Python + AWS | 149건 | 0.320 |
| AWS + CI/CD | 135건 | 0.372 |
| React + Next.js | 128건 | 0.516 |
| Python + SQL | 128건 | 0.348 |

## 4. 주요 인사이트

### 인사이트 1. 데이터 분석가는 Python보다 SQL을 더 자주 요구한다

데이터 분석가 공고 71건 중 SQL은 59건(83.1%), Python은 43건(60.6%)에서 등장했습니다.

SQL의 등장률은 Python보다 약 22.5%p 높았습니다.

### 인사이트 2. LLM은 다양한 개발 직무에서도 요구된다

전체 724건 중 202건에서 LLM이 등장했습니다.

데이터 사이언티스트의 LLM 등장률은 56%로 가장 높았으며, 등장 공고 수는 백엔드가 73건으로 가장 많았습니다.

### 인사이트 3. 경력에 따른 요구 기술 수의 차이는 크지 않다

- 0~1년: 평균 7.0개
- 2~4년: 평균 7.5개
- 5년 이상: 평균 7.7개

경력 수준이 높아질수록 평균 기술 수는 소폭 증가했지만, 큰 차이를 보이지 않았습니다.

### 인사이트 4. 데이터 엔지니어는 여러 직무와 유사한 기술 구성을 보인다

데이터 엔지니어의 기술 등장률 패턴은 데이터 분석가(0.65), 데이터 사이언티스트(0.65), 백엔드(0.64)와 비교적 높은 코사인 유사도를 보였습니다.

## 8. 데이터 공개 및 재현성

원본 채용공고 CSV, 상세 JSON 캐시 및 SQLite 데이터베이스는 Git 추적 제외 대상으로 관리합니다.

데이터 수집 및 적재 코드는 다음과 같이 실행할 수 있도록 구성했습니다.

```bash
python src/collect_wanted.py
python src/build_db.py
```

외부 API의 접근 정책이나 채용공고 내용은 변경될 수 있으므로 동일한 데이터와 분석 결과가 항상 재현되는 것은 아닙니다.

## 9. 분석의 한계

- 원티드 단일 플랫폼의 채용공고를 분석했습니다.
- 직무별 분석 공고 수가 서로 다릅니다.
- 스킬 사전 기반 추출이므로 등록되지 않은 기술은 누락될 수 있습니다.
- 기술의 등장 여부만으로 실제 요구 숙련도나 업무 중요도를 판단할 수 없습니다.
- 분석 결과는 채용시장 전체의 수요나 실제 채용 성과를 직접적으로 설명하지 않습니다.

## 10. 프로젝트 결론

IT 직무별로 요구되는 기술에는 차이가 있으며, 기술의 등장률과 상대적 특징, 함께 요구되는 기술 조합을 종합적으로 고려하는 것이 중요합니다.

본 프로젝트는 채용공고 데이터를 활용하여 직무별 기술 요구 패턴을 정량적으로 비교하고, 취업 준비 과정에서 기술 학습 우선순위를 결정하는 데 참고할 수 있는 근거를 제시합니다.


# 채용공고 분석을 통해 발견한 4가지 인사이트

## 1. 분석 개요

본 문서는 채용공고 기반 직무별 요구 기술 분석 결과에서 확인한 주요 발견을 정리한 것이다.

단순한 기술 등장 빈도를 넘어 직무별 요구 기술의 차이, LLM 관련 기술의 요구 현황, 경력에 따른 요구 기술 수, 직무 간 기술 구성의 유사성을 분석하였다.

분석 결과는 원티드(Wanted) 채용공고 1,273건에서 중복 공고를 정리한 1,267건 중 5개 직무로 재분류된 705건을 기준으로 한다.

수치는 `python run_all.py`로 재현할 수 있으며, 실행 결과는 `outputs/logs/`에 저장된다. 분류와 기술 추출을 검증하고 보정한 과정은 [분석 보고서](analysis_report.md)의 2.3에 정리하였다.

## 2. 주요 발견

### 발견 1. 데이터 분석가는 Python보다 SQL을 더 자주 요구한다

데이터 분석가 채용공고 71건 중 SQL은 59건(83.1%), Python은 43건(60.6%)에서 등장하였다.

SQL의 등장률은 Python보다 약 **22.5%p** 높았다.

표본이 71건으로 작아 Wilson 95% 신뢰구간을 계산하면 SQL은 73~90%, Python은 49~71%였다.

같은 공고 안에서 두 기술을 짝지어 비교하면 다음과 같다.

| 구분 | 공고 수 |
|---|---:|
| SQL만 요구 | 20건 |
| Python만 요구 | 4건 |
| 둘 다 요구 | 39건 |
| 둘 다 요구하지 않음 | 8건 |

SQL만 요구한 공고(20건)가 Python만 요구한 공고(4건)보다 많았고, McNemar 정확검정 결과 p = 0.002로 두 기술의 요구 비율 차이는 우연으로 보기 어려웠다. 이는 데이터 분석가를 준비할 때 Python뿐 아니라 SQL 역량도 중요하게 고려해야 함을 보여준다.

직무별로 보면 SQL은 데이터 분석가(83%)와 데이터 엔지니어(63%)에서 주로 요구되었고, Python은 데이터 사이언티스트(72%)와 데이터 엔지니어(70%)에서 가장 많이 요구되었다.

#### 시사점

데이터 분석가를 목표로 한다면 Python 학습과 함께 SQL을 활용한 데이터 조회, 가공 및 분석 역량을 확보하는 것이 도움이 될 수 있다.

다만 기술의 등장률이 실제 업무 비중이나 요구 숙련도를 의미하는 것은 아니므로, 학습 우선순위를 정하는 참고 지표로 해석해야 한다.

### 발견 2. LLM은 데이터 사이언티스트뿐 아니라 다른 직무에서도 요구된다

LLM은 데이터 사이언티스트뿐 아니라 데이터 엔지니어, 백엔드, 프론트엔드 등 다양한 직무의 채용공고에서도 등장하였다.

직무별 LLM 등장률과 공고 수는 다음과 같다.

| 직무 | 분석 공고 수 | LLM 등장률 (95% 신뢰구간) | LLM 등장 공고 수 |
|---|---:|---:|---:|
| 데이터 분석가 | 71건 | 7% (3~15%) | 5건 |
| 데이터 엔지니어 | 92건 | 30% (22~40%) | 28건 |
| 데이터 사이언티스트 | 155건 | 55% (47~62%) | 85건 |
| 백엔드 | 227건 | 22% (17~28%) | 50건 |
| 프론트엔드 | 160건 | 18% (12~24%) | 28건 |

#### 분석 결과

- **등장률 기준:** 데이터 사이언티스트가 55%로 가장 높았다.
- **공고 수 기준:** 데이터 사이언티스트가 85건으로 가장 많았고, 백엔드가 50건으로 그다음이었다.
- **전체 공고 기준:** 705건 중 196건(27.8%)에서 LLM이 등장하였다.
- **직무 분포:** LLM이 등장한 196건 중 111건(57%)은 데이터 사이언티스트가 아닌 직무의 공고였다.

데이터 사이언티스트는 LLM 등장률이 가장 높아 해당 직무에서 LLM 관련 기술이 상대적으로 자주 요구되는 것으로 나타났다.

그러나 데이터 엔지니어(30%), 백엔드(22%), 프론트엔드(18%)에서도 LLM이 등장하였다. 이는 LLM 관련 기술이 데이터 사이언티스트에만 국한되지 않고 다른 직무의 채용공고에서도 요구되고 있음을 보여준다.

다만 데이터 사이언티스트 직무 분류 규칙에는 제목에 `LLM`이 들어간 공고가 포함되어 있다. 데이터 사이언티스트의 LLM 공고 85건 중 16건은 제목에 LLM이 있어 분류 단계에서 이미 LLM이 반영된 공고이므로, 해당 직무의 LLM 등장률은 다소 높게 나왔을 수 있다.

#### 시사점

LLM 관련 기술을 학습할 때는 인공지능 모델 개발뿐 아니라 기존 서비스와의 연동 및 활용 관점도 고려할 필요가 있다.

다만 LLM이 채용공고에 등장했다는 사실만으로 해당 직무에서 직접 모델을 개발하거나 운영한다고 단정할 수는 없다.

### 발견 3. 경력이 높아져도 요구 기술 수는 크게 증가하지 않는다

일반적으로 경력이 높아질수록 더 많은 기술을 요구할 것으로 예상할 수 있다.

이를 확인하기 위해 채용공고의 경력 구간별로 공고당 요구 기술 수의 평균과 중앙값을 비교하였다.

| 경력 구간 | 공고 수 | 평균 기술 수 | 중앙값 | 표준편차 |
|---|---:|---:|---:|---:|
| 0~1년 | 131건 | 6.4개 | 6개 | 4.6개 |
| 2~4년 | 294건 | 7.1개 | 6개 | 4.0개 |
| 5년 이상 | 273건 | 7.2개 | 7개 | 4.1개 |
| 경력 정보 없음 | 7건 | 6.9개 | 6개 | 5.0개 |

#### 분석 결과

- **0~1년:** 평균 6.4개의 기술이 등장하였다.
- **2~4년:** 평균 7.1개의 기술이 등장하였다.
- **5년 이상:** 평균 7.2개의 기술이 등장하였다.

경력이 높아질수록 공고당 평균 요구 기술 수는 소폭 높아지는 경향이 있었다.

그러나 0~1년과 5년 이상 구간의 평균 차이는 **0.8개**로 구간별 표준편차(4.0~4.6개)보다 훨씬 작았다. 경력 정보가 없는 공고를 제외한 세 구간을 Kruskal-Wallis 검정으로 비교한 결과 H = 5.79, p = 0.055로, 5% 유의수준에서는 통계적으로 유의한 차이가 없었으나 경계에 가까운 값이었다.

따라서 경력이 높아진다고 해서 채용공고에 명시되는 기술의 개수가 크게 증가한다고 보기는 어려웠다.

#### 시사점

경력 수준에 따른 기술 요구의 차이는 단순한 기술 개수보다 요구되는 기술의 종류, 숙련도, 실무 경험 등에서 나타날 가능성이 있다.

다만 본 분석에서는 채용공고에 등장한 기술의 개수만 비교하였으므로, 실제 요구 숙련도나 업무 난이도의 차이까지 확인한 것은 아니다.

### 발견 4. 데이터 엔지니어는 여러 직무와 유사한 기술 구성을 보인다

직무별 요구 기술이 얼마나 유사한지 확인하기 위해 각 직무의 스킬 등장률을 벡터로 표현하고, 코사인 유사도를 계산하였다.

코사인 유사도는 두 벡터의 방향이 얼마나 유사한지 나타내는 지표이다. 이번 분석에서는 값이 1에 가까울수록 두 직무의 기술 등장률 패턴이 유사하다는 의미로 해석하였다.

직무 간 코사인 유사도는 다음과 같다.

| 직무 | 데이터 분석가 | 데이터 엔지니어 | 데이터 사이언티스트 | 백엔드 | 프론트엔드 |
|---|---:|---:|---:|---:|---:|
| 데이터 분석가 | 1.00 | 0.64 | 0.53 | 0.28 | 0.08 |
| 데이터 엔지니어 | 0.64 | 1.00 | 0.64 | 0.67 | 0.20 |
| 데이터 사이언티스트 | 0.53 | 0.64 | 1.00 | 0.57 | 0.24 |
| 백엔드 | 0.28 | 0.67 | 0.57 | 1.00 | 0.42 |
| 프론트엔드 | 0.08 | 0.20 | 0.24 | 0.42 | 1.00 |

#### 분석 결과

- **데이터 엔지니어 - 백엔드:** 유사도 0.67
- **데이터 엔지니어 - 데이터 분석가:** 유사도 0.64
- **데이터 엔지니어 - 데이터 사이언티스트:** 유사도 0.64
- **백엔드 - 데이터 사이언티스트:** 유사도 0.57
- **백엔드 - 프론트엔드:** 유사도 0.42
- **데이터 분석가 - 프론트엔드:** 유사도 0.08

데이터 엔지니어는 백엔드와 0.67, 데이터 분석가 및 데이터 사이언티스트와 각각 0.64의 유사도를 보였다.

이는 데이터 엔지니어가 데이터 관련 직무뿐 아니라 백엔드와도 비교적 유사한 기술 요구 패턴을 가지며, 세 직무 중 백엔드와 가장 유사하다는 점을 보여준다.

반면 데이터 분석가와 프론트엔드의 유사도는 0.08로 낮게 나타나 두 직무의 기술 구성이 뚜렷하게 다름을 확인할 수 있었다.

#### 시사점

데이터 엔지니어는 데이터 처리와 분석뿐 아니라 서버 및 인프라 관련 기술도 함께 학습하는 것이 도움이 될 수 있다.

또한 직무 간 기술 요구의 유사성을 활용하면 기존에 학습한 기술을 바탕으로 인접 직무로 역량을 확장하는 방향을 검토할 수 있다.

다만 코사인 유사도는 기술 등장률 패턴의 유사성을 나타내는 지표이며, 실제 업무 내용이나 직무 간 이직 가능성을 직접적으로 의미하지는 않는다.

## 3. 분석의 한계 및 주의사항

본 프로젝트는 채용공고에 등장하는 기술을 정량적으로 분석하여 직무별 요구 기술의 특징을 파악하였다. 그러나 결과를 해석할 때 다음과 같은 한계를 고려해야 한다.

### 3.1 데이터 수집 범위의 한계

- **단일 플랫폼:** 원티드(Wanted)에서 수집한 채용공고만 분석하였으므로 전체 IT 채용시장의 요구 기술을 대표한다고 보기 어렵다.
- **수집 시점:** 특정 시점에 수집한 데이터를 기반으로 하므로 시간에 따른 기술 수요의 변화를 확인하기 어렵다.
- **직무별 표본 차이:** 직무별 분석 공고 수가 71~227건으로 서로 달라 등장 공고 수를 직접 비교할 때 주의가 필요하다. 표본이 작은 직무(데이터 분석가 71건)는 비율의 불확실성이 크므로 신뢰구간을 함께 확인해야 한다.

### 3.2 기술 추출 및 직무 분류의 한계

- **스킬 사전 기반 추출:** 표준 기술명 90개와 별칭 211개를 기준으로 기술을 추출하였으므로 사전에 등록되지 않은 기술은 분석에서 누락될 수 있다.
- **텍스트 매칭의 한계:** 기술명이 등장했다는 사실만으로 해당 기술의 필수 여부나 요구 숙련도를 정확하게 판단하기 어렵다. 표본 점검에서도 `GitHub 포트폴리오`, `엑셀 내보내기 기능 구현`처럼 숙련 요구로 보기 어려운 문맥이 일부 확인되었다.
- **직무 분류의 한계:** 채용공고의 제목을 기준으로 재분류하였다. 제외된 공고를 표본으로 점검했을 때 규칙으로 잡을 수 있는 누락은 약 6%였지만, 제목에 직무 키워드가 없는 공고는 구분하기 어려워 일부 누락이 남아 있을 수 있다. 점검 기준은 한 사람이 판단한 것이다.
- **풀스택 제외:** 프론트엔드와 백엔드의 기술이 섞이는 풀스택 공고 86건은 분석에서 제외하였다.
- **LLM 분류 중복:** 데이터 사이언티스트 분류 규칙에 제목의 LLM이 포함되어 있어 해당 직무의 LLM 등장률은 다소 높게 나올 수 있다.

### 3.3 분석 지표 해석의 한계

- **등장률:** 기술이 채용공고에 나타난 비율이며, 실제 업무에서의 사용 빈도나 중요도를 직접적으로 의미하지 않는다.
- **TF-IDF:** 직무 5개를 비교 단위로 계산하여 등장률 순위를 거의 그대로 따르므로, 직무 고유 기술은 해당 직무와 다른 직무의 등장률 차이(%p)를 함께 확인하였다.
- **Jaccard 유사도:** 두 기술이 함께 등장하는 비율을 나타내지만, 기술 간 의존관계나 인과관계를 의미하지 않는다.
- **코사인 유사도:** 직무별 기술 요구 패턴의 유사성을 나타내며, 실제 업무 내용이나 직무 간 전환 가능성을 직접적으로 설명하지 않는다.
- **경력별 기술 수:** 공고에 등장한 기술의 개수를 비교한 것으로, 경력에 따른 기술 숙련도나 업무 난이도의 차이를 설명하지는 않는다.
- **통계 검정:** 여러 지표에 대해 검정을 수행하였으나 다중 비교 보정은 하지 않았으므로 p값은 참고용으로 해석해야 한다.

## 4. 최종 정리

이번 분석에서는 채용공고에 명시된 기술을 바탕으로 다음과 같은 네 가지 특징을 확인하였다.

1. **SQL의 중요성:** 데이터 분석가 공고에서는 Python보다 SQL의 등장률이 높았고, 같은 공고 안에서의 비교에서도 차이가 통계적으로 유의하였다.
2. **LLM의 다양한 직무 요구:** LLM이 등장한 공고의 57%는 데이터 사이언티스트가 아닌 직무의 공고였다.
3. **경력별 기술 수의 차이:** 경력이 높아질수록 평균 요구 기술 수는 소폭 높아졌지만, 그 차이는 크지 않았고 통계적으로 유의하지 않았다.
4. **직무 간 기술 유사성:** 데이터 엔지니어는 백엔드, 데이터 분석가, 데이터 사이언티스트와 비교적 유사한 기술 요구 패턴을 보였으며 특히 백엔드와 가장 유사하였다.

이러한 결과는 직무별 기술 학습 방향을 설정하고, 인접 직무와의 기술적 연관성을 이해하는 데 참고 자료로 활용할 수 있다.
